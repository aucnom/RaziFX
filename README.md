# Razi FX Project

## The Topic
RaziFX is an open source, cross-platform desktop program written in the Java programming language and using the javafx framework.
This program deals with the financial management of a small workshop.

---



## The requirements
1. [ZuluFX v8.82.0.2](https://www.azul.com/downloads/?package=jdk#zulu) was used to create the Razi software.
  ZuluFX provides a convenient way to obtain a JDK with JavaFX included.
2. [NetBeans v24](https://netbeans.apache.org/front/main/index.html) IDE was used to build and develop this project.
   NetBeans is an open-source Integrated Development Environment (IDE) primarily used for developing Java applications.
3. [Docker v4.35.2](https://www.docker.com/products/docker-desktop/) The #1 containerization software for developers and teams.
   * Pull the MySQL Docker Image and run using command:
   - `docker pull mysql:latest`
   + `docker run -d --name "ContainerName" -e MYSQL_ROOT_PASSWORD="PASSWORD" -e MYSQL_DATABASE=my_database_name -v my_mysql_data:/var/lib/mysql -p 3306:3306`
4. [mysqlWorkbench 8.0.40.CE](https://www.mysql.com/products/workbench/) is a unified visual tool for database architects, developers, and DBAs. MySQL Workbench provides data modeling, SQL development, and comprehensive administration tools for server configuration, user administration, backup, and much more.
5. [mysql-connector-java v.1.9.0](https://dev.mysql.com/downloads/connector/j/) is the official JDBC driver for MySQL.
6. [Hibernate v5](https://hibernate.org/orm/releases/)  is an open-source Object-Relational Mapping (ORM) framework for the Java programming language.
